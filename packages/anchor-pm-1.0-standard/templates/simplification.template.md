# Anchor PM Simplification Log

This file prevents rule and document growth.

Before adding a new coordination document, check whether the content belongs in:

- `.threadsmith/AGENTS.md`
- `.threadsmith/contracts.md`
- `.threadsmith/module_state/<thread>.md`
- an existing reference document

## Current Simplification Decisions

- Thread contracts live in one file: `.threadsmith/contracts.md`.
- Long-term thread state lives only under `.threadsmith/module_state/`.
